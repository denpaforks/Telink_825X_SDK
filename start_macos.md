# macOS development environment

An official macOS TC32 compiler package is not included in this repository, and the current project has no verified native macOS build procedure.

Use a supported 64-bit Linux environment, a Linux virtual machine, or WSL2 on Windows. See [Linux setup](start_linux.md).
