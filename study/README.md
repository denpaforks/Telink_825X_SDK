# Bluetooth learning projects

This directory combines small firmware projects with explanatory material for learning Bluetooth Low Energy on the Ai-Thinker TB-02 Kit.

Suggested Android test application: `BLE Utility`.

## Course order

1. [00 Hello World](00_HelloWorld/README.md) — validate build, flash, and UART output.
2. [01 Advertising](01_Advertise/README.md) — configure advertising data and parameters.
3. [02 Slave connection](02_Slave_Connect/README.md) — accept a BLE connection and observe callbacks.
4. [03 UUID](03_UUID/README.md) — define services and characteristics.

The project names and output names are historical; for example, `00_HelloWorld` produces an ELF named `iBeacon.elf`.
